# Tilt Photography

The M42 → Sony E tilt adapter changes the orientation of the focal plane. Start with small movements: strong tilt can make focus placement difficult.

The SMC Takumar can use this adapter because it has an M42 mount. The Minolta MC-mount Beroflex cannot.

Possible experiments:

- Place the focus plane along a receding surface.
- Deliberately narrow the sharp band for a miniature effect.
- Repeat the same composition with no tilt as a control.
